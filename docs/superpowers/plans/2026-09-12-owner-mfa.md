# Owner-Only MFA Enforcement Implementation Plan

**Goal:** Require the production Owner account to complete MFA before any protected backend access while leaving employee enforcement unchanged.

**Architecture:** Keep Better Auth sessions, native expiry/refresh, passkey/TOTP/recovery flows, and staff session markers. Change only the server-side MFA decision so an identity whose stored role is `owner` is never grandfathered past MFA; employee identities continue to use the existing rollout policy.

**Tech Stack:** Next.js, Better Auth 1.6.25, Drizzle, Vitest, TypeScript.

## Constraints

- Do not change employee login requirements.
- Do not add a 12-hour or 60-minute timeout.
- Do not create, edit, or execute a database migration.
- Do not expose credentials, MFA secrets, or recovery codes.
